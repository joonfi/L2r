# Security Policy

## Supported Versions

| Version | Status |
|--------:|--------|
| 1.x     | Supported |
| <1.0    | End-of-life |

## Reporting a Vulnerability
Do **not** open public issues. Contact: https://irradi.ato.rs

## Coordinated Disclosure
Default 90 days unless actively exploited or open a pull request as soon as possible.

## Local/Dev Hardening
Local/dev practical demonstration only but built for production requirements in mind; if you'll use it and transition to production make sure not to expose it publicly without hardening (and depending on your context probably doing your due diligence) first i.e. tooling and platform used/instantiated here may have been already outdated unless you run the prompt to build the script.
